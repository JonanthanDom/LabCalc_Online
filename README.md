# LabCalc

Sistema laboratorial online desenvolvido para auxiliar profissionais da área da saúde e laboratórios 
na realização de cálculos clínicos, conversões e automações laboratoriais de forma rápida, prática e padronizada.

---

# Objetivo

O LabCalc tem como objetivo centralizar ferramentas laboratoriais em uma única plataforma, reduzindo erros manuais, 
aumentando a produtividade e facilitando a rotina de profissionais de laboratório.
O projeto foi pensado para evoluir futuramente para um ecossistema completo integrado ao BioRack.

---

# Funcionalidades

## MVP Inicial

- Cálculos laboratoriais
